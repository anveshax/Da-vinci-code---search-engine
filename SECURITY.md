## Reporting a Vulnerability

The ANVESHA team takes system security, agent sandboxing, and crawler safety seriously.

If you discover a security vulnerability (such as SSRF bypass, prompt injection escalation, unauthorized tool execution, or sensitive data leakage):

1. **Do not create a public GitHub issue.**
2. Send a report via email or open a [Private Security Advisory](https://github.com/anveshax/Da-vinci-code---search-engine/security/advisories/new) on GitHub.
3. Include detailed steps to reproduce the vulnerability, including payload examples and affected endpoints or components.

We will review your submission and provide an initial response within 48 hours.
